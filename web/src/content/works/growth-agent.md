> **在线体验：** [https://ai-sales-growth-agent.vercel.app/](https://ai-sales-growth-agent.vercel.app/)

为验证销售 AI 智能体方案可行性，独立设计并开发的可交互产品 Demo（已部署上线）。

## 产品形态

定义「AI 销售副驾驶」产品形态，围绕销售「**该跟谁、说什么、要不要转人工**」的决策链路，设计三大模块：

- **运营总览 Dashboard** —— 线索与转化的整体态势一屏掌握
- **AI 对话分析** —— 单次模型调用并行输出六维结构化分析
- **用户 360° 画像** —— 会话数据沉淀为可行动的画像与标签

## 核心设计

- **六维结构化分析**：通过 Prompt Engineering 使单次模型调用并行输出意图分类、阶段判断、风险评估、策略建议、推荐话术与人工接管决策，各判断均附置信度与推理依据；
- **话术规则**：在对话原型中植入产品知识与真实竞品定价知识库，设计共情优先、风险兜底、不确定即转人工的话术规则。

## 技术栈

Next.js + TypeScript + DeepSeek API
